# Netflix (maqueta)

Ejercicio de la semana 3 del bootcamp de [Hack a Boss](https://hackaboss.com/): **maqueta de la página de inicio de Netflix** hecha con HTML y CSS.

> 🚧 Está a medio hacer: la estructura de secciones está montada (cabecera con logo y selector de idioma, bloques «Disfruta», «Descárgate» y «Crea perfiles», y preguntas frecuentes), pero varios textos y elementos están vacíos.

## Cómo verlo

Abre `index.html` en el navegador. No necesita instalar nada.

## Estructura

```
index.html
style.css
*.png, *.jpg    # logo, fondo e imágenes de dispositivos
```
